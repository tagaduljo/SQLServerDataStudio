What the application does

SQL Server Data Studio is a desktop database viewer. You choose a SQL Server and authentication method. The application connects directly to that server to read the database catalog, object definitions, descriptions, and records you request. Database results may contain personal or confidential information depending on the server and your permissions. Connect only to servers and data you are authorized to access.

Connections and credentials

For Windows Authentication, Windows supplies your current account's authentication to the selected server. For SQL Server Authentication, the username and password you enter are used to authenticate directly to that server. SQL usernames and passwords are not saved to configuration files. They are held in process memory for the connection session. Connection pooling is disabled. The password entry is cleared after connecting and when the login window closes.

Encryption is enabled and certificate validation is required by default. Changing Encrypt connection or Trust server certificate changes the protection of communications with your selected server. Your database administrator controls the server's authentication, access permissions, encryption support, auditing, and retention of server logs.

Local information and preferences

The application reads local SQL Server instance names from Windows registry entries to populate the server selector. It reads the Windows app color preference when Use Windows setting is selected. It does not broadcast discovery requests across your network.

The saved connection preferences contain the server name, authentication method, encryption and certificate-trust choices, record limit, and default object views. Both editions store these in C:\ProgramData\Blue Works Labs\SQL Server Data Studio\server.json. Report, widget and dashboard definitions are stored in report.json, widget.json and dashboard.json in the same folder, organized by server instance and database. These definitions include names, descriptions, source objects, selected columns, custom report column headings, order, preview column widths, decimal places and date/time display choices, related tables and foreign-key mappings, filters, limits and dashboard membership, but not result rows or credentials. Shared files may be readable by other Windows users with folder access. Color theme and layout density are stored per Windows user in local application data (package LocalState for a Store installation). Demo definitions and browsing preferences are isolated from your real library and server selection.

Database results are displayed in memory and are not automatically exported, uploaded, or written to application logs. Professional Edition's Export CSV writes the currently loaded report to the file you choose. If you explicitly copy a value, grid selection, or SQL definition, it is placed on the Windows clipboard. Clipboard history, synchronization, other applications, exports and files you create are controlled by you and Windows.

Preview Report captures the currently displayed report rows and presentation in memory without making another SQL Server request. Grouping, count, selected numeric sum fields, total scopes and column-width choices are saved in the applicable report definition so they can be restored on a later run. These settings contain field identities and display choices, not result rows or calculated totals. Preview pages are released when the preview closes. Professional Edition's Export XPS writes those pages, including their displayed data, to your chosen file. Professional Edition's Print / PDF sends the pages to the printer you select; a physical or network printer may retain jobs under its own settings, and Microsoft Print to PDF writes a file at your chosen location. These documents may contain confidential database data and remain until you remove them.

Data sharing and collection

Blue Works Labs does not operate a backend for this application and the application does not send database contents, credentials, telemetry, analytics, or advertising identifiers to Blue Works Labs. There are no advertisements or tracking SDKs. Database requests go directly to the SQL Server you select. Your server may use its own infrastructure and logging. The offline demo uses fictional data bundled with the application and makes no database connection.

The Store edition uses Microsoft Store services to check subscription entitlements, retrieve product prices, restore purchases and process purchases you request. Microsoft handles the account, payment information, billing and subscription management. This app does not receive your payment card details or send database results to the Store. Manage subscription opens Microsoft's account services website in your browser.

To support temporary Store verification failures, the Store edition saves the subscription product identifier, last successful license-check time, known expiration, and last recovery-use time in store-license.dat in its private local application data. Windows protects this file for the current Windows user, and it is scoped to this application package. It contains no Microsoft account name, payment information, SQL credentials or database results. Recovery can retain Professional access for up to 72 hours after the last successful license check, capped at the known subscription expiration. A successful check confirming no active subscription invalidates recovery. The file is updated locally and is not sent to Blue Works Labs; Windows manages its removal with private package data.

The Microsoft Store, Windows, and your SQL Server may independently collect installation, diagnostic, account, or operational information under their own settings and privacy policies. If you choose Email support, your configured mail application opens. Any message or attachments you send are shared with Blue Works Labs through your email provider and are used to respond to your request. Do not send database passwords or confidential records. You can request access to or deletion of support correspondence by contacting blueworkstech@outlook.com; legally required records may need to be retained.

Your controls and retention

You choose which server to connect to and which objects and records to inspect. Close the application to end its active session. Change remembered preferences in the login and Settings windows, or remove saved definitions through the library. Close the app before manually removing preference files; the About window shows the shared directory. Shared ProgramData files and exported reports remain after uninstall until you or your administrator remove them. Windows manages removal of private package data. Cancelling a subscription does not delete your saved definitions. Your database administrator controls actual database records; this application does not edit or delete them.

Children

This application is a database administration and development tool. It is not directed to children and does not require a Blue Works Labs account.

Changes and questions

This policy is updated when the application's data handling changes. The current policy is included in About & privacy. Contact Blue Works Labs at blueworkstech@outlook.com with privacy or support questions.
